# Roadmap

## Phase 1 — local prototype (current)

Ledger, supply rules, test signatures, local miner, AI-job metadata, API, explorer and tests.

## Phase 2 — multi-node devnet

Peer networking, durable storage, mempool rules, difficulty adjustment, chain synchronization, pool protocol and signed desktop builds.

## Phase 3 — useful-compute testnet

Containerized workloads, GPU capability discovery, deterministic job profiles, result commitments, redundant verification, escrow, staking and slashing.

## Phase 4 — security and scale

ML-DSA hybrid wallets, key migration, fuzzing, attack simulations, formal review, independent audits and transparent performance benchmarks.

## Phase 5 — public launch review

Legal/regulatory review, public testnet incentives, bug bounty, genesis process and only then a mainnet readiness decision.
