# Security policy

KOREK v0.1 is research software and must not hold real value. Report vulnerabilities privately to the repository owner rather than opening a public exploit report.

Before mainnet, the project requires threat modelling, dependency pinning, reproducible signed releases, secret encryption, hardware-wallet design, ML-DSA integration, protocol fuzzing, denial-of-service testing, at least two independent audits and a public bug bounty.

No software can truthfully guarantee that it is unhackable or permanently quantum-proof. KOREK instead aims for cryptographic agility, conservative key handling, rapid upgrades and independently reviewed standards.
